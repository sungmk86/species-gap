# 2026-12-04 워크숍 2회 GitHub

3회 중 2회다.
오늘은 GitHub다.

오늘 할 일:

1. 한국(Windows) 브라우저에서 공용 실험노트 창고(GitHub)를 연다.
2. 태국 연구소 컴퓨터(minlab1)에 전화(SSH)한다.
3. 이 창고의 공개 사본만 받는다.

다음 회는 Rosetta다.

나라는 계속 한 쌍이다.
노트북은 한국(Windows)이다.
연구소 컴퓨터는 태국(Linux)이다.

암호, 토큰, 비밀번호는 이 종이에 적지 않는다.
종이(파일) 안에 넣지도 않는다.

## 창고가 뭔가

창고(GitHub)는 공용 실험노트 보관 장소다.
브라우저로 보면 손짓으로 주문(그래픽 화면)해서 읽는 것이다.
사본 받기(clone)는 태국 컴퓨터에 같은 노트를 한 벌 내려받는 것이다.

오늘은 읽기 연습이다.
고치지 않는다.
창고에 다시 올리지 않는다.

공개 창고 `species-gap`만 본다.
주소는 `https`로 시작한다.

## 1. 창고(GitHub)를 브라우저로 열기

이 단계는 전화(SSH)가 필요 없다.
한국(Windows) 노트북에서 브라우저를 연다.
주소창에 아래를 붙인다.

```text
https://github.com/sungmk86/species-gap
```

공개 창고다.
읽기만 하면 로그인하지 않아도 된다.
암호를 넣지 않는다.
토큰을 만들지 않는다.

이름 목록이 방(폴더)과 종이(파일)다.
`README.md`는 창고 앞문 안내문이다.
`workshops`를 누르면 유인물 방이다.
그 안의 `README.md`는 날짜와 주제 표다.
`notes`를 누르면 회차별 종이가 있다.

위쪽 `Code`는 사본 받는 단추다.
지금은 눌러도 되고, 안 눌러도 된다.
조금 뒤 태국 컴퓨터에서 말로 사본을 받는다.

다 보면 브라우저를 켜 둔 채로 안내데스크(터미널)로 간다.

## 2. 새 가이드(PowerShell)에서 전화(SSH)

한국 안내데스크(터미널)에서 새 가이드(PowerShell)를 연다.
오래된 가이드(CMD)는 오늘도 열지 않는다.

```powershell
ssh 아이디@192.9.177.175   # 태국 연구소 컴퓨터에 전화한다
```

`아이디`만 본인 계정으로 바꾼다.
암호는 이 종이에 적지 않는다.

태국 가이드(Bash)가 받으면 이런 줄이다.
줄 끝이 `$`이면 된다.

```text
아이디@minlab1:~$
```

이제 말은 태국 가이드(Bash)에게 한다.

집 방(홈 폴더)인지 확인한다.

```bash
pwd   # 지금 방 주소를 묻는다
```

집 방이면 `/home/아이디`처럼 보인다.

## 3. 공용 실험노트 창고(GitHub)에서 사본 받기

이미 `species-gap` 방이 있으면 받는 명령을 건너뛴다.

있는지 먼저 본다.

```bash
ls   # species-gap 방이 있는지 본다
```

없으면 집 방(홈 폴더)에서 사본을 받는다.

```bash
git clone https://github.com/sungmk86/species-gap.git   # 공개 창고에서 노트 사본을 받는다
```

주소는 `https`로 시작한다.
암호 창이나 토큰 창이 뜨면 중단하고 강사에게 알린다.

받은 방으로 들어간다.

```bash
cd species-gap   # 받은 노트 방으로 들어간다
```

안을 본다.

```bash
ls   # 이 방의 목록을 본다
```

`workshops` 방이 보이면 사본이 맞은 것이다.

그 방으로 들어간다.

```bash
cd workshops   # 유인물 방으로 들어간다
```

다시 본다.

```bash
ls   # README.md와 notes 방을 확인한다
```

`README.md`와 `notes`가 보이면 충분하다.

노트 방으로 들어간다.

```bash
cd notes   # 회차별 종이 방으로 들어간다
```

```bash
ls   # 오늘 종이 이름을 확인한다
```

`20261204.md`가 보이면 오늘 종이를 찾은 것이다.
내용을 고치지 않는다.
창고에 다시 올리지 않는다.

## 4. 나가기

집 방으로 돌아온다.

```bash
cd   # 집 방으로 돌아온다
```

전화(SSH)를 끊는다.

```bash
exit   # 전화를 끊고 한국으로 돌아온다
```

한국 안내 줄이 다시 보이면 된 것이다.

오늘 성공은 이것이다.

1. 브라우저로 공개 창고를 열었다.
2. 전화(SSH)로 minlab1에 들어갔다.
3. `git clone`으로 이 창고 사본을 받았다.
4. `workshops/notes/`에서 오늘 종이를 확인했다.
