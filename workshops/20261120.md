## 
노트북의 세상(운영체제)은 한국(Windows)이다.
연구소 컴퓨터의 세상(운영체제)은 태국(Linux)이다.
여행은 한 번이다.
나라는 이 두 곳만 쓴다.

손짓으로 주문(그래픽 화면)하면, 컴퓨터 말을 몰라도 메뉴를 누를 수 있다.
오늘은 손짓이 아니라 안내데스크(터미널)에서 가이드(셸)에게 말로 시킨다.

한국 안내데스크에는 가이드가 둘 있다.
오래된 가이드(CMD)도 있다.
새 가이드(PowerShell)는 더 많은 일을 할 수 있다.
오늘은 새 가이드(PowerShell)만 연다.

전화(SSH)는 노트북을 태국으로 옮기지 않는다.
한국 의자에 앉아서, 태국 연구소 컴퓨터(minlab1)에 전화하는 것이다.

전화가 연결되면 태국 가이드(Bash)가 받는다.
그다음 말은 모두 태국 가이드(Bash)에게 한다.

단백질 모양을 계산하는 태국 연구소 기구는 PyRosetta다.
명령줄 Rosetta 묶음이 설치되어 있다고 보지 않는다.
오늘은 PyRosetta만 쓴다.

## 1. 새 가이드(PowerShell) 열기

한국(Windows)에서 시작 옆 검색창에 `PowerShell`을 친다.
Windows PowerShell을 연다.

이런 줄이 나오면 된다.

```text
PS C:\Users\이름>
```

`이름`은 본인 한국(Windows) 계정 이름이다.

검색창에 `cmd`를 치면 오래된 가이드(CMD)도 나온다.
오늘은 열지 않는다.

## 2. 지금 위치 묻기

같은 질문이다.
“지금 어디예요?”

새 가이드(PowerShell) 고유의 말은 `Get-Location`이다.

```powershell
Get-Location   # 지금 어디인지 묻는다
```

짧은 말 `pwd`도 새 가이드(PowerShell)가 알아듣는다.

```powershell
pwd   # 같은 질문의 짧은 말
```

둘 다 같은 뜻이다.
말투만 조금 다르다.
`pwd`는 오래된 가이드(CMD)만의 말이 아니다.

지금 위치가 노트북의 한국 방이면 된다.

## 3. 왜 태국(Linux)인가

단백질 모양을 계산하는 기구(PyRosetta)는 태국 연구소 컴퓨터(minlab1)에 있다.
그 컴퓨터의 세상(운영체제)은 태국(Linux)이다.
노트북 세상(운영체제)을 바꿀 필요는 없다.
한국에 앉아서 전화(SSH)만 건다.

## 4. 태국 연구소 컴퓨터(minlab1)에 전화(SSH)

`아이디`만 본인 계정으로 바꾼다.

```powershell
ssh 아이디@192.9.177.175   # 태국 연구소 컴퓨터에 전화한다
```

처음이면 확인 질문에 `yes`를 입력한다.
접속 방법은 당일 강사가 안내한다.
암호는 이 종이에 적지 않는다.

연결되면 태국 가이드(Bash)가 받는다.
컴퓨터 이름은 `minlab1`이다.
줄 끝이 `$`이면 된다.

```text
아이디@minlab1:~$
```

이 줄이 보이면 한국 안내데스크가 아니라, 태국 연구소 컴퓨터 안에 있는 것이다.

## 5. 실험대 칸막이(conda 환경) 켜기

실험대는 칸막이(conda 환경)로 나뉘어 있다.
기구(PyRosetta)는 `rosetta` 칸에 있다.

```bash
conda activate rosetta   # rosetta 칸막이를 켠다
```

앞에 `(rosetta)`가 있고, 줄 끝이 `$`이면 성공이다.

```text
(rosetta) 아이디@minlab1:~$
```

## 6. 그 칸에서 쓰는 말(Python) 열기

```bash
python   # 그 칸의 말을 연다
```

이런 줄이 나오면 된다.

```text
>>>
```

`>>>`는 그 칸의 말(Python)이 준비됐다는 뜻이다.

## 7. 단백질 하나 읽고 점수(score) 출력

`단백질.pdb`는 임시 이름이다.
당일 강사가 실제 파일 이름을 알려 주면 그 이름으로 바꾼다.

아래를 한 덩어리로 붙여 넣는다.

```python
import pyrosetta
pyrosetta.init()
pose = pyrosetta.pose_from_pdb("단백질.pdb")  # 좌표 종이에서 자세를 만든다
scorefxn = pyrosetta.get_score_function()
print(scorefxn(pose))  # 점수 한 줄을 본다
```

초기화 글이 길게 나와도 당황하지 않는다.
마지막에 소수점 숫자 한 줄이 나오면 된다.

```text
123.45
```

`123.45`는 자리만 보여주는 예다.
숫자는 파일마다 다르다.
오늘 본 숫자는 실험에서 잰 에너지가 아니다.
오늘 다른 단백질과 비교하지 않는다.

자세(pose)와 점수(score)의 뜻은 3회에서 이어 본다.

## 8. 나가기

그 칸의 말(Python)에서 나온다.

```python
exit()   # 그 칸의 말을 끝낸다
```

태국 전화(SSH)를 끊는다.

```bash
exit   # 전화를 끊고 한국으로 돌아온다
```

다시 한국 안내 줄이 보이면 된 것이다.

```text
PS C:\Users\이름>
```
