# 2026-11-20 PyRosetta 워크숍 1회 (초안)

3회 중 1회다.
시간은 1시간이다.
각자 Windows 노트북을 쓴다.
공용 컴퓨터는 imac1이다.
imac1은 Ubuntu다.
계정은 이미 있다.
PyRosetta는 conda 환경 `rosetta`에 설치되어 있다.
버전은 `2026.39+release.49e05e797c`이다.

이번 시간에는 단백질 파일 하나를 읽고 점수를 출력한다.

## 1. PowerShell 열기

노트북에서 PowerShell을 연다.

이런 줄이 나오면 된다.

```text
PS C:\Users\이름>
```

`이름`은 본인 Windows 계정 이름이다.

## 2. imac1에 접속

`아이디`를 본인 imac1 계정으로 바꾼다.

```text
ssh 아이디@192.9.177.175
```

처음이면 확인 질문에 `yes`를 입력한다.
암호는 입력해도 화면에 안 보인다.

접속되면 이런 줄이 나온다.

```text
아이디@imac1:~$
```

컴퓨터 이름은 예시이다. 줄 끝이 `$`이면 된다.

## 3. rosetta 환경 켜기

```text
conda activate rosetta
```

이런 줄이 나온다.

```text
(rosetta) 아이디@imac1:~$
```

앞에 `(rosetta)`가 있으면 된다.

## 4. Python 열기

```text
python
```

이런 줄이 나온다.

```text
>>>
```

## 5. 단백질 하나 읽고 점수 출력

`단백질.pdb`는 임시 이름이다.
당일 강사가 파일 이름을 알려 준다. 그 이름으로 바꾼다.
아래를 붙여 넣는다.

```python
import pyrosetta
pyrosetta.init()
pose = pyrosetta.pose_from_pdb("단백질.pdb")
scorefxn = pyrosetta.get_score_function()
print(scorefxn(pose))
```

초기화 글이 길게 나온 뒤, 마지막에 소수점 숫자 한 줄이 나오면 된다.

```text
123.45
```

숫자는 파일마다 다르다. `123.45`는 자리만 보여주는 예다.
