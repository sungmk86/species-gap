## 4. 좌표 종이(PDB)에서 자세(pose) 만들기

자세(pose)는 단백질 한 장의 좌표 묶음이다.
원자들이 지금 어디에 놓여 있는지를 한 덩어리로 들고 있는 것이다.

단백질 좌표 종이(PDB)를 읽으면 자세(pose)가 만들어진다.

```python
pose = pyrosetta.pose_from_pdb("단백질.pdb")  # 좌표 종이에서 자세를 만든다
print(pose.total_residue())  # 잔기 개수를 본다
print(pose.sequence())  # 서열 한 줄을 본다
```

마지막 숫자는 잔기(아미노산 단위) 개수다.
이 숫자도 파일마다 다르다.
예시 숫자를 실제 측정처럼 쓰지 않는다.

## 5. 점수(score)가 뭔가

점수(score)는 그 자세가 계산상 얼마나 편한지 보여주는 숫자다.
같은 길이, 같은 단백질에서 숫자가 낮을수록 더 편한 쪽에 가깝다.

이 숫자는 실험에서 잰 에너지가 아니다.
실험 노트에 kcal, kJ로 적지 않는다.
길이가 다른 단백질끼리 이 숫자를 비교하지 않는다.
오늘 한 파일만 본다.

```python
scorefxn = pyrosetta.get_score_function()  # 기본 점수표를 가져온다
print(scorefxn(pose))  # 점수 한 줄을 본다
```

초기화 글이 이미 나왔으면, 마지막에 소수점 숫자 한 줄만 보면 된다.

```text
123.45
```

`123.45`는 자리만 보여주는 예다.
숫자는 파일마다 다르다.

시간이 있으면 점수표를 펼쳐 본다.
항(term) 이름이 여러 줄로 나온다.
오늘 그 이름을 외우지 않아도 된다.

```python
scorefxn.show(pose)  # 점수 항을 펼쳐 본다
```

## 6. 시간이 남으면: 하나 바꾸고 곁사슬 다시 넣기(pack)

이 단계는 선택이다.
앞 단계가 안 되면 여기서 멈추고 강사에게 알린다.

아미노산 하나를 바꾸면, 그 자리와 가까운 곁사슬(side chain)도 다시 맞춰야 한다.
그 다시 맞추기를 packing이라고 한다.

`자리`는 자세(pose) 번호다.
PDB 번호와 다를 수 있다.
당일 강사가 자리와 아미노산 한 글자를 알려 준다.

```python
from pyrosetta.toolbox import mutate_residue

원래 = pose.clone()  # 바꾸기 전 자세를 복사한다
자리 = 10  # 임시 번호. 당일 강사가 알려 주면 바꾼다
mutate_residue(pose, 자리, "A", pack_radius=8.0, pack_scorefxn=scorefxn)  # 하나 바꾸고 근처를 다시 넣는다
print(scorefxn(원래), scorefxn(pose))  # 같은 길이에서만 비교한다
```

두 숫자는 같은 단백질, 같은 길이다.
낮은 쪽이 계산상 더 편한 쪽에 가깝다.
이 차이도 실험 에너지가 아니다.
