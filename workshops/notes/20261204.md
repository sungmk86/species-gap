## 내 Linux 컴퓨터에 `conda`를 이용하여 `foundry` 설치
1. conda 설치
```
curl -fL -o /home/minlab1/Downloads/Miniconda3-latest-Linux-x86_64.sh https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh   # 공식 Miniconda 설치 파일
bash /home/minlab1/Downloads/Miniconda3-latest-Linux-x86_64.sh -b -p /home/minlab1/miniconda3

source /home/minlab1/miniconda3/etc/profile.d/conda.sh
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/main   # 기본 프로그램 사용 조건에 동의
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/r   # R 언어 사용 조건에 동의

conda install -n base -c conda-forge mamba -y   # base 방에 mamba를 설치
conda init bash   # 다음 터미널부터 conda가 자동으로 켜지게 함
```

|구분| 설명|
|--|--|
|curl|인터넷에서 파일이나 데이터를 가져오는 프로그램|
| conda|가상환경 관리 프로그램 |
|miniconda3| Python 3 기반 Miniconda 설치 프로그램. Python과 Conda를 포함한 가벼운 설치 배포판|
|source| 현재 Shell 내부에서 스크립트를 실행하는 명령어|
|tos| 이용 약관(Terms of Service) 관련 기능|
|channel| 패키지 다운로드하는 repository|
|mamba| Conda와 호환되는 빠른 패키지 관리 도구|

2. foundry 환경 만들기
```bash
# requires-python = ">=3.12"
# Foundry의 개발 및 테스트 설정이 Python 3.12를 기준으로 작성 됨.
# 2026년 11월 23일 기준, Python의 최신 정식 버전은 Python 3.15.2
conda create -n foundry python=3.12
conda activate foundry
```
3. foundry 설치
```bash
pip install "rc-foundry[all]"
```
4. 현재까지 AI가 학습하면서 얻은 기본 모델 가중치 다운로드
   - RF3가 단백질 구조를 예측하려면 과거 학습을 통해 만들어진 모델의 가중치가 필요함.
   - 이 과정 없이 예측 작업 수행할 수 없음.
   - `~/.foundry/checkpoints/` 에 저장됨.
   - 아래 명령어를 통해 최신 RFD3, RF3, MPNN의 학습된 모델 파일을 내려받게 됨.
```
foundry install base-models
```
- Foundry에서 다운로드할 수 있는 모델 목록 보기
```
foundry list-available 
```
- 다운로드 된 모델 가중치 목록 보기
```
foundry list-installed 
```

4. RoseTTAFold3(RF3) 실행
```
rf3 fold \
    inputs='입력파일.json' \
    out_dir='results/rf3'
```
