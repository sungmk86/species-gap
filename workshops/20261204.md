# 2026-12-04 워크숍 2회

3회 중 2회다.

오늘 할 일:

1. 한국(Windows)에서 다시 전화(SSH)한다.
2. 태국 가이드(Bash)에게 방(폴더)과 종이(파일)를 묻는다.
3. 칸막이(conda 환경) `rosetta`를 다시 켠다.
4. 공용 실험노트 창고(GitHub)에서 공개 사본만 받는다.

다음 회: 자세(pose)와 점수(score) 뜻, 창고(GitHub)를 브라우저로 열기.

나라는 계속 한 쌍이다.
노트북은 한국(Windows)이다.
연구소 컴퓨터는 태국(Linux)이다.

## 1. 새 가이드(PowerShell) 열고 전화(SSH)

한국 안내데스크(터미널)에서 새 가이드(PowerShell)를 연다.
오래된 가이드(CMD)는 오늘도 열지 않는다.

```powershell
ssh 아이디@192.9.177.175   # 태국 연구소 컴퓨터에 전화한다
```

`아이디`만 본인 계정으로 바꾼다.
암호는 이 종이에 적지 않는다.

태국 가이드(Bash)가 받으면 이런 줄이다.
줄 끝이 `$`이면 된다.

```text
아이디@minlab1:~$
```

이제 말은 태국 가이드(Bash)에게 한다.

## 2. 지금 방 주소 보기

`pwd`는 “지금 어디예요?”다.
1회에서 한국 가이드(PowerShell)에게도 같은 짧은 말을 했다.
지금은 태국 가이드(Bash)에게 묻는 것이다.
글자는 같고, 대상만 다르다.

```bash
pwd   # 지금 방 주소를 묻는다
```

집 방(홈 폴더)이면 대략 이렇게 보인다.

```text
/home/아이디
```

## 3. 이 방에 뭐가 있나 보기

방(폴더) 안의 종이(파일)와 다른 방을 본다.

```bash
ls   # 이 방의 종이와 다른 방을 본다
```

이름이 여러 줄로 나오면 된다.
오늘 그 이름을 외우지 않아도 된다.

## 4. 다른 방으로 이동

누구나 있는 임시 방 `/tmp`로 들어가 본다.

```bash
cd /tmp   # 임시 방으로 들어간다
```

다시 주소를 확인한다.

```bash
pwd   # 지금 방 주소를 묻는다
```

주소 끝에 `tmp`가 붙어 있으면 이동한 것이다.

한 단계 위 방으로 나간다.

```bash
cd ..   # 한 단계 위 방으로 나간다
```

집 방(홈 폴더)으로 바로 돌아온다.

```bash
cd   # 집 방으로 돌아온다
```

한 번에 명령은 하나씩만 친다.
길을 잃으면 `pwd`를 다시 친다.

## 5. 칸막이(conda 환경) 다시 켜기

기구(PyRosetta)는 여전히 `rosetta` 칸에 있다.
전화(SSH)를 새로 하면 칸막이는 꺼져 있다.
쓸 때마다 다시 켠다.

```bash
conda activate rosetta   # rosetta 칸막이를 켠다
```

앞에 `(rosetta)`가 있고, 줄 끝이 `$`이면 성공이다.

```text
(rosetta) 아이디@minlab1:~$
```

그 칸의 말(Python)이 열리는지만 본다.

```bash
python   # 그 칸의 말을 연다
```

```text
>>>
```

바로 나온다.

```python
exit()   # 그 칸의 말을 끝낸다
```

오늘 점수는 다시 계산하지 않아도 된다.

## 6. 공용 실험노트 창고(GitHub)에서 사본 받기

창고(GitHub)는 공용 실험노트 보관 장소다.
오늘은 읽기 연습이다.
고치지 않는다.
암호를 넣지 않는다.

공개 창고 `species-gap`만 받는다.
이미 `species-gap` 방이 있으면 받는 명령을 건너뛴다.

있는지 먼저 본다.

```bash
ls   # species-gap 방이 있는지 본다
```

없으면 집 방(홈 폴더)에서 사본을 받는다.

```bash
git clone https://github.com/sungmk86/species-gap.git   # 공개 창고에서 노트 사본을 받는다
```

주소는 `https`로 시작한다.
암호 창이 뜨면 중단하고 강사에게 알린다.

받은 방으로 들어간다.

```bash
cd species-gap   # 받은 노트 방으로 들어간다
```

안을 본다.

```bash
ls   # 이 방의 목록을 본다
```

`workshops` 방이 보이면 사본이 맞은 것이다.

그 방으로 들어간다.

```bash
cd workshops   # 유인물 방으로 들어간다
```

다시 본다.

```bash
ls   # 오늘 종이 이름을 확인한다
```

오늘 종이(파일) 이름이 보이면 충분하다.
내용을 고치지 않는다.
창고에 다시 올리지 않는다.

## 7. 나가기

집 방으로 돌아온다.

```bash
cd   # 집 방으로 돌아온다
```

전화(SSH)를 끊는다.

```bash
exit   # 전화를 끊고 한국으로 돌아온다
```

한국 안내 줄이 다시 보이면 된 것이다.
