## 5. 점수 출력

```python
import pyrosetta
# import glob
# files = sorted(glob.glob("pdbs/*.pdb"))

pyrosetta.init()

files = ["a.pdb", "b.pdb", "c.pdb"]
score = pyrosetta.get_score_function()

for name in files:
    pose = pyrosetta.pose_from_pdb(name)
    print(name, score(pose))
```
